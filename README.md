# Web Design Experiment 1

This project demonstrates a simple responsive webpage using HTML and CSS. It shows basic GitHub repository concepts, GitHub Pages publishing, navigation, page sections, and a clean footer layout.

## Features

- Header and navigation bar
- Home, About, and Contact sections
- Internal anchor navigation
- Responsive viewport setup
- Simple dark-themed header and footer
- Embedded CSS styling
- No external dependencies

## Technologies Used

- HTML5
- CSS3

## Project Files

| File | Description |
| --- | --- |
| `Experiment1.html` | Main webpage containing the HTML structure and CSS |

## How to Run

1. Download or clone the repository.
2. Open `Experiment1.html` in a web browser.

The page can also be previewed using a local server such as VS Code Live Server.

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/Experiment1.html`.

## GitHub Pages

1. Push `Experiment1.html` to a GitHub repository.
2. Open **Settings** in the repository.
3. Select **Pages**.
4. Choose the main branch as the deployment source.
5. Save the settings.
6. Open the published GitHub Pages URL.
